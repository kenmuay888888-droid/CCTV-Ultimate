# CCTV-Ultimate
CCTV Ultimate Personal Edition คือระบบ Private CCTV สำหรับ Windows ที่เปลี่ยน Laptop หรือ Desktop ให้เป็นกล้องวงจรปิดส่วนตัว พร้อมบันทึกภาพ/เสียง ดู Live และย้อนหลังผ่านโทรศัพท์ด้วย Tailscale VPN รองรับกล้องในตัวและ USB Webcam ตรวจสอบฮาร์ดแวร์อัตโนมัติ ติดตั้งง่าย ย้ายเครื่องได้ และลบไฟล์อัตโนมัติตามเวลาที่กำหนด
